# Course Ledger

A Code Cowboys golf courses-played ledger. Not a rangefinder. Not a
scorecard. The book of everywhere you've played — courses, when, with
whom, one score, the story.

- Package id: `com.codecowboys.courseledger` · Domain: mycourseledger.app
- Privacy-first, local-only (Drift/sqlite), no accounts, no analytics.
- Built on [`cc_core`](https://github.com/Mark-Code-Cowboys/cc_core)
  pinned by tag; local iteration via git-ignored `pubspec_overrides.yaml`
  (`path: ../CC_Core`).
- cc_core gaps and new-generic candidates are tracked in
  [`docs/cc-core-gaps.md`](docs/cc-core-gaps.md).
